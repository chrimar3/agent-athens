# Security policy

Agent Athens is an open-source events calendar for Athens. Its pipeline
scrapes public websites, reads newsletters, runs AI enrichment and publishes
https://agentathens.com. We take reports about any of that seriously.

## Reporting a vulnerability

Please **do not open a public issue or pull request** for a security problem.

Report it privately through GitHub: the repository's **Security** tab →
**Report a vulnerability**. Include what you found, where (file, URL or
pipeline step), how to reproduce it, and the impact you expect.

You can expect:

- an acknowledgement within **7 days**;
- an assessment and a planned fix date within **14 days**;
- credit in the fix's release notes if you want it.

## In scope

- Code in this repository: the site generator, scrapers, email ingestion, the
  enrichment tooling and its guards, the Netlify configuration (the site runs
  no Netlify functions or edge functions), CI workflows and the container
  setup under `docker/`.
- The published site, https://agentathens.com: cross-site scripting, open
  redirects, header or configuration weaknesses.
- Ways that content from a scraped page, a newsletter, or an issue or pull
  request could make the automation do something it should not (prompt
  injection, command execution, credential exposure, unwanted publishing).

## Out of scope

- Denial-of-service or load testing against the live site or its sources.
- Findings that need an already-compromised maintainer machine or account.
- Missing best-practice headers with no demonstrated impact.
- Reports generated by automated scanners without a working reproduction.

## Testing rules

Test against your own clone and a local build (`bun run build && bun run
serve`). Against the live site, use only ordinary browsing requests. Never
access, change or delete data that isn't yours, and never try credentials you
found — report them instead. Good-faith research within these rules will not
be pursued.

## Supported versions

Only the `main` branch and the currently deployed site are supported.
