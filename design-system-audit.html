4. Accessibility (Live Site)

What's passing

WCAG AA contrast — all text passes

Primary text at 18.43:1, secondary at 7.01:1, tertiary at 4.5:1+. No sub-12px fonts anywhere on the site. All 33 images have alt text. Proper landmarks: <main>, <header role="banner">, <footer role="contentinfo">, <nav aria-label>. Skip link present. Heading hierarchy correct (H1→H2→H3, no skips). Reduced motion preference respected.

Issues found

Critical Search input has no accessible label

The <input type="search"> has only a placeholder — no aria-label, no <label>, no aria-labelledby. Screen readers cannot identify this field. Fix: add aria-label="Αναζήτηση εκδηλώσεων".

Major "Read More" button below 44px touch target

The "Περισσότερα ▾" button measures 114x36px — below the WCAG 2.5.5 minimum of 44px height. Fix: add min-height: 44px to .edp-read-more.

5. Naming Conventions
