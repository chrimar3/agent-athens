### Issue 3a — Canonical points to a 301-redirect target

Homepage at `/` declares canonical = `/index`. But `/index` itself 301-redirects to `/`. Google's canonicalization rule: a declared canonical that itself redirects is a weak/invalid signal — Google may pick its own canonical or split authority. **This is the highest-impact technical block.**

**Source:** `src/templates/page.ts:92`

```typescript
<link rel="canonical" href="${BASE_URL}/${url}">
```

The homepage passes `url="index"` (intended for "English-readable URL" per comment on line 91), producing `/index`. The other site templates use trailing slashes consistently:

- `src/templates/content-page.ts:61` → `${BASE_URL}/${slug}/` ✓
- `src/generators/event-page.ts:327` → `/events/${slug}/` ✓
- `src/generators/venue-page.ts:111` → `/venues/${slug}/` ✓

`page.ts` is the outlier: no trailing slash AND uses a synthetic slug (`index`) instead of empty string for the homepage.

### Issue 3b — Incomplete hreflang

Only `<link rel="alternate" hreflang="el">` is emitted (`src/templates/page.ts:95`). Per Google's spec, hreflang declarations must be paired (or omitted entirely). A single unpaired `el` declaration is invalid and will be ignored. The English mirror at `/en/today/` is not declared as the `en` alternate, so Google has no signal that an English version exists.

## Classification: Class B — Technical block found

The site is technically reachable and not blocked at robots/sitemap level. AI search crawlers are explicitly invited. Schema, sitemap, security headers all clean. But two homepage-level signal issues are present:

### Specific blocks for remediation session

1. **Homepage canonical loop** (`src/templates/page.ts:92`)
   Homepage at `/` declares canonical = `/index`, but `/index` 301-redirects to `/`. Fix: emit `${BASE_URL}/` for the homepage (or change `url="index"` → `url=""` and add a trailing-slash branch). Affects every page generated through `page.ts` that uses synthetic slugs.

2. **Unpaired hreflang** (`src/templates/page.ts:95`)
   Only `hreflang="el"` is declared. Either remove (Greek-only stance per memory) or pair with `<link rel="alternate" hreflang="en" href="${BASE_URL}/en/today/">` and `<link rel="alternate" hreflang="x-default" href="${BASE_URL}/">`. Decision required: is the English mirror first-class for SEO, or unlisted?

3. **GSC verification file is build-orphan** (`dist/googled03df0efd969df1f.html`)
   Move to `static/root-files/` to survive clean rebuilds. Low risk, mechanical.

4. **English homepage redirect chain** (`/en/` → `/en/today` → `/en/today/`)
   Two-hop redirect on the English entry point. If English is a target market for SEO, collapse to a single 301 or serve `/en/today/` content directly at `/en/`.
