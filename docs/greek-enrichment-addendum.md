## Γιατί υπάρχει αυτό το addendum

Το Master Template (v2.5) και το Enrichment Knowledge Base σχεδιάστηκαν για αγγλικές περιγραφές. Τα ελληνικά descriptions γράφονται χειροκίνητα εξαρχής — δεν μεταφράζονται. Η ποιότητα αυτών δεν μπορεί να αξιολογηθεί ή να αναπαραχθεί χωρίς δική τους τεκμηρίωση.

Αυτό το addendum δεν αντικαθιστά το Master Template. Το συμπληρώνει. Κάθε κανόνας που ΔΕΝ αναφέρεται εδώ ισχύει αυτούσιος από το αγγλικό template. Εδώ τεκμηριώνονται μόνο τα σημεία που διαφέρουν ή χρειάζονται ελληνική εξειδίκευση.

# ΜΕΡΟΣ 1: ΑΡΧΙΤΕΚΤΟΝΙΚΗ ΠΕΔΙΩΝ

## Πού πηγαίνει κάθε περιγραφή

| Πεδίο βάσης | Περιεχόμενο | Γλώσσα anchor | Σημειώσεις |
|---|---|---|---|
| `full_description_en` | Αγγλική περιγραφή | "Athens" | Για διεθνές κοινό + AI engines σε αγγλικά queries |
| `full_description_gr` | Ελληνική περιγραφή | «Αθήνα» | Για ελληνικό κοινό + AI engines σε ελληνικά queries |
| `description` | Σύντομη περιγραφή scraper | Όπως έρχεται | Legacy field — δεν τροποποιείται χειροκίνητα |

## Schema.org Bilingual Rendering

Κάθε event page renderάρει δύο JSON-LD blocks — ένα `@language: "en"` και ένα `@language: "el"`. Η ελληνική περιγραφή τροφοδοτεί:

- `description` στο `@language: "el"` JSON-LD block
- `og:description` στο ελληνικό locale
- `<meta name="description">` στο ελληνικό URL path

Αυτό σημαίνει ότι η ελληνική περιγραφή δεν είναι secondary content — είναι ισότιμο citation surface για ελληνόφωνα AI queries.

### Fallback chain (known limitation)

Ο site generator χρησιμοποιεί priority chain: `fullDescEn || fullDescGr || fullDescLegacy`. Αγγλικά πρώτα, ελληνικά fallback. Αν ένα event έχει αγγλική περιγραφή αλλά όχι ελληνική, η ελληνική σελίδα (`/events/{slug}/`) θα δείξει αγγλικό κείμενο. Αυτό σημαίνει ότι η ελληνική περιγραφή δεν είναι απλά «ωραίο να υπάρχει» — χωρίς αυτή, η ελληνική σελίδα σερβίρει αγγλικά σε ελληνόφωνο χρήστη.

### Save-batch behavior (safe by default)

Η enrichment pipeline γράφει `.md` → `full_description_en` και `.gr.md` → `full_description_gr`. Αν κάνεις re-enrich μόνο αγγλικά (χωρίς `.gr.md` file), τα ελληνικά δεν πειράζονται. Αν στείλεις `.gr.md`, overwrites — last write wins, no merge logic. Κανόνας: μη στέλνεις `.gr.md` αν δεν θέλεις να αντικαταστήσεις την υπάρχουσα ελληνική περιγραφή.

### Hub pages bug (Sprint 4b)

Τα hub pages (`/en/today/`, `/en/this-weekend/` κλπ) έχουν hardcoded `inLanguage: "el"` ακόμα και στα `/en/` paths. Αυτό είναι confirmed bug (page.ts:413) — δεν επηρεάζει τις event page περιγραφές, αλλά σημαίνει ότι τα English hubs δηλώνουν λάθος γλώσσα στο structured data.

# ΜΕΡΟΣ 2: ΕΛΛΗΝΙΚΟ CITATION ANCHOR

## Το Pattern

Η πρώτη πρόταση κάθε ελληνικής περιγραφής ακολουθεί δηλωτικό pattern αντίστοιχο με το αγγλικό:

```
[Όνομα εκδήλωσης] είναι [τύπος] στ[ο/η/ην] [Χώρος] στ[ο/η/ην] [Γειτονιά], Αθήνα, στις [Ημερομηνία].
```

### Τα 6 υποχρεωτικά entities

| Entity | Αγγλικό | Ελληνικό | Παράδειγμα |
|---|---|---|---|
| Όνομα εκδήλωσης | Event name | Τίτλος στα ελληνικά | Ο Καπετάν Σαματάς |
| Keyword τύπου | "concert," "exhibition" | «συναυλία,» «έκθεση,» «παράσταση» | παιδική συναυλία |
| Χώρος | Venue name | Σε ελληνικό ή λατινικό script (βλ. κανόνα Μέρος 3) | Μέγαρο Μουσικής Αθηνών |
| Γειτονιά | Neighborhood | Ελληνικά | Αμπελόκηποι |
| Πόλη | "Athens" | «Αθήνα» | Αθήνα |
| Ημερομηνία | Date reference | Ελληνικό format | στις 3 Μαρτίου 2026 |

### Keywords τύπου εκδήλωσης (ελληνικά)

| Αγγλικό keyword | Ελληνικό keyword | Σημειώσεις |
|---|---|---|
| concert | συναυλία | «παιδική συναυλία» για kids concerts |
| exhibition | έκθεση | |
| theater | θεατρική παράσταση | Ή σκέτο «παράσταση» αν ο τύπος φαίνεται αλλιώς |
| dj_set | DJ set | Παραμένει αμετάφραστο — ο ελληνικός χρήστης αναζητά "DJ set" |
| festival | φεστιβάλ | |
| sports | αθλητική διοργάνωση / αγώνας | Εξειδικεύεται: «αγώνας πυγμαχίας,» «αγώνας δρόμου» |
| show | παράσταση | «stand-up παράσταση,» «cabaret» |
| cinema | προβολή | |
| kids | παιδική παράσταση / παιδικό θέατρο | Εξειδικεύεται ανά μορφή |

### Παραδείγματα σωστών anchor sentences

**Kids concert:**
> Ο Καπετάν Σαματάς είναι παιδική συναυλία στο Μέγαρο Μουσικής Αθηνών, στους Αμπελοκήπους, στις 3 Μαρτίου 2026.

**DJ set:**
> Το FERMA Label Night είναι DJ set στο Astron στο Γκάζι, Αθήνα, στις 13 Μαρτίου 2026.

**Theater:**
> Ο Λούτσιο και το ταξίδι στον πλανήτη Κιαροσκούρο είναι παιδική θεατρική παράσταση στο Θέατρο Μαβίλη στους Αμπελόκηπους, Αθήνα, στις 3 Μαρτίου 2026.

### Αποδεκτές παραλλαγές anchor

Το «είναι» είναι ο default. Ορισμένοι τύποι εκδηλώσεων έχουν φυσικότερη σύνταξη με άλλο ρήμα. Αποδεκτό, εφόσον τα 6 entities παραμένουν στην πρώτη πρόταση και η πρόταση είναι δηλωτική (factual, not sensory):

- Ρεσιτάλ: «δίνει ρεσιτάλ» αντί «είναι ρεσιτάλ» — π.χ. «Η Μαρία Ευστρατιάδη δίνει ρεσιτάλ πιάνου στον Φιλολογικό Σύλλογο Παρνασσός...»
- Established event: «επιστρέφει» αντί «είναι» — π.χ. «Το Athens Epidaurus Festival επιστρέφει στο Ηρώδειο...» (μόνο αν υπάρχει ιστορία)
- Αθλητική ομάδα σε εκτός έδρας: «αγωνίζεται» αντί «είναι αγώνας»

Αν αμφιβάλλεις, «είναι» δουλεύει πάντα.

### Η σειρά είναι αδιαπραγμάτευτη

Πρόταση 1 = δηλωτικό anchor. Πρόταση 2+ = αισθητηριακή μεταφορά. Ποτέ ανάποδα.

Η αισθητηριακή πρόταση πρώτη («Ένα πέπλο αιωρείται αργά πάνω από τη σκηνή...») δημιουργεί ωραίο κείμενο αλλά αποτυχημένο citation surface — ένα AI engine δεν μπορεί να εξάγει χρήσιμη πληροφορία από εικόνα χωρίς context.

# ΜΕΡΟΣ 4: WORD COUNT MATRIX (ΕΛΛΗΝΙΚΑ)

## Ο συντελεστής

Τα ελληνικά εκφράζουν ίδιο νόημα σε λιγότερες λέξεις από τα αγγλικά. Η εμπειρική αναλογία από τα τρέχοντα batches είναι **~86% του αγγλικού μήκους**. Ο ελληνικός matrix εφαρμόζει αυτόν τον συντελεστή:

| Τύπος εκδήλωσης | Αγγλικό εύρος | Ελληνικό εύρος | Σημειώσεις |
|---|---|---|---|
| Έκθεση | 200-300 | 170-260 | |
| Συναυλία (μεγάλη) | 120-200 | 100-170 | |
| Συναυλία (τοπική/DJ) | 80-120 | 70-100 | |
| Παιδικά/Οικογενειακά | 120-180 | 100-155 | |
| Φεστιβάλ (γονική σελίδα) | 250-400 | 215-345 | |
| Φεστιβάλ (υπο-εκδήλωση) | 80-150 | 70-130 | |
| Θέατρο (αρχαίο δράμα) | 180-250 | 155-215 | |
| Θέατρο (σύγχρονο) | 120-180 | 100-155 | |
| Premium showcase | 400-600 | 345-515 | Πλήρης δομή 8 ενοτήτων |

**Ο κανόνας δεν αλλάζει:** τα ceilings είναι ceilings, όχι στόχοι. Μια περιγραφή DJ set στις 75 ελληνικές λέξεις που νοιώθεις τον χώρο είναι καλύτερη από μια στις 100 με padding.

## Πότε ξεπερνάμε το ceiling

Μόνο αν η περιγραφή classify-αριστεί ρητά ως premium showcase. Για παράδειγμα, μια παιδική συναυλία στο Μέγαρο Μουσικής σε τέταρτη σεζόν sold out *μπορεί* να δικαιολογήσει premium treatment — αλλά αυτό πρέπει να αποφασιστεί πριν τη γραφή, όχι μετά, ως δικαιολογία για υπέρβαση.

# ΜΕΡΟΣ 8: ΕΛΛΗΝΙΚΕΣ ΙΔΙΑΙΤΕΡΟΤΗΤΕΣ ΓΛΩΣΣΑΣ

## Β' ενικό vs. Β' πληθυντικό

Τα αγγλικά "you" δεν έχουν αυτό το πρόβλημα. Τα ελληνικά ναι.

| Register | Χρήση | Παράδειγμα |
|---|---|---|
| Β' πληθυντικό (εσείς) | **Default** — τα πάντα | «Αν θέλετε...» |
| Β' ενικό (εσύ) | Μόνο σε nightlife / DJ sets / underground | «Αν θέλεις σαφείς απαντήσεις...» |

Ο κανόνας: το register πρέπει να ταιριάζει με τον χώρο. Μέγαρο Μουσικής = πληθυντικό πάντα. Astron = ενικό δουλεύει. Red Jasper = ενικό ή πληθυντικό ανάλογα με τον τόνο. Αν αμφιβάλλεις, πληθυντικό.

**Μην αναμειγνύεις register μέσα στην ίδια περιγραφή** εκτός αν υπάρχει σκόπιμη εναλλαγή κοινού (π.χ. filter section που απευθύνεται σε διαφορετική ομάδα).

## Τόνοι και ορθογραφία

Τα ελληνικά descriptions πρέπει να είναι ορθογραφικά σωστά — τόνοι, σωστή χρήση τελικού ν, σωστές κλίσεις. Αυτό δεν είναι στυλιστική επιλογή, είναι αξιοπιστία. Ένα ελληνικό description με ορθογραφικά λάθη σηματοδοτεί στο AI engine ότι η πηγή δεν είναι αξιόπιστη.

## Χρόνος ρήματος

Ίδιος κανόνας με τα αγγλικά: **ενεστώτας**. «Τα σχοινιά τεντώνονται,» όχι «τα σχοινιά τεντώθηκαν.» «Η αίθουσα γεμίζει,» όχι «η αίθουσα γέμισε.»

## Αριθμοί

| Τι | Κανόνας | Παράδειγμα |
|---|---|---|
| Τιμές | Αριθμητικά + EUR | 15 EUR, 28 EUR |
| Χωρητικότητα | Ολογράφως ή αριθμητικά — consistency εντός περιγραφής | «χωράει εκατόν πενήντα» ή «χωράει 150» — και τα δύο OK |
| Ώρες | 24ωρο format | 21:00, 23:00 |
| Ηλικίες | Ολογράφως | «από δέκα μηνών έως τριών ετών» |
| Ημερομηνίες | Πλήρεις | 3 Μαρτίου 2026, 29 Μαρτίου 2026 |

## Filter section — φυσική ελληνική σύνταξη

Ο αγγλικός κανόνας «If you... / If you...» μεταφράζεται σε:

```
Αν θέλετε [αυτό που ΔΕΝ θα βρείτε εδώ], [γιατί δεν ταιριάζει].
Αν όμως θέλετε [αυτό που ΟΝΤΩΣ προσφέρει], [γιατί αξίζει].
```

Ή σε ενικό (nightlife):
```
Αν θέλεις [X], λάθος κτίριο.
Αν θέλεις [Y], αυτή είναι η Αθήνα μετά τα μεσάνυχτα.
```

Η δομή «αν... / αν όμως...» ή «αν... / αν...» είναι η ελληνική φυσική μετάφραση του honest filter. Η αντίθεση πρέπει να είναι γνήσια — όχι ένα ψεύτικο «αν δεν θέλετε / αν θέλετε» που λέει ουσιαστικά «ελάτε πάντως.»

## Exemplar B: Mid-Range Kids Theater — Λούτσιο

**Τύπος:** Παιδικό θέατρο | **Εύρος:** 100-155 λέξεις | **Δομή:** Hybrid | **Register:** Πληθυντικό

---

Ο Λούτσιο και το ταξίδι στον πλανήτη Κιαροσκούρο είναι παιδική θεατρική παράσταση στο Θέατρο Μαβίλη στους Αμπελόκηπους, Αθήνα, στις 3 Μαρτίου 2026. Στον πλανήτη Κιαροσκούρο, όλοι λάμπουν από τα συναισθήματά τους. Ώσπου ένα αγόρι μετακομίζει σε πόλη που κανείς δεν λάμπει.

Σε κείμενο Βλάσση Χρυσικόπουλου και σκηνοθεσία Φρύνης Θετάκη, η παράσταση ακολουθεί τον Λούτσιο από τη φωτεινή Ιλούμινα Αουρέλια στη σκοτεινή Ομπρόζα Νοτούρνα, όπου η διαφορετικότητά του φέρνει εκφοβισμό. Τρεις ηθοποιοί από Το Καραβάνι με τα Παραμύθια, μουσική Γιάννη Κουφουδάκη, σκηνικά Αντωνίας Μαρκαντωνάτου.

Αν τα παιδιά σας χρειάζονται συνεχή θόρυβο, αυτή η παράσταση δουλεύει πιο ήσυχα. Αν αναγνωρίζουν πώς νιώθεις όταν είσαι το μόνο φωτεινό σημείο σε σκοτεινό δωμάτιο, ο Λούτσιο μιλάει τη γλώσσα τους.

Δορυλαίου 10-12, πλατεία Μαβίλη. Μετρό Μέγαρο Μουσικής, πέντε λεπτά. Κυριακές 11:00. Εισιτήρια από 8 EUR.

Μια ιστορία για το πώς κρατάς το φως σου όταν όλα γύρω σου λένε να το σβήσεις.

## Exemplar C: Corrected Inverted Opening — Του-του

**Τύπος:** Κουκλοθέατρο (kids) | **Εύρος:** 100-155 λέξεις | **Δομή:** Hybrid | **Register:** Πληθυντικό

Αυτό το exemplar δείχνει τη μετατροπή inverted → corrected opening, χωρίς απώλεια sensory ποιότητας.

### ΠΡΙΝ (inverted — FAIL):
> Ένα πέπλο αιωρείται αργά πάνω από τη σκηνή και σαράντα ζευγάρια μικρά μάτια το ακολουθούν σαν σμήνος. Ο Του-του και η Τσαφ-τσουφ είναι...

### ΜΕΤΑ (corrected — PASS):

---

Ο Του-του και η Τσαφ-τσουφ είναι παράσταση κουκλοθέατρου για μωρά στο θέατρο Olvio στον Βοτανικό, Αθήνα, κάθε Κυριακή έως 5 Απριλίου 2026. Ένα πέπλο αιωρείται αργά πάνω από τη σκηνή και σαράντα ζευγάρια μικρά μάτια το ακολουθούν σαν σμήνος.

Η Ιρίνα Μπόικο σκηνοθετεί και ερμηνεύει μαζί με την Ελένη Γκρίβα — δύο φίλοι κούκλες, ένα αυτοκινητάκι και ένα τρενάκι, σε σαράντα λεπτά διαδραστικού θεάτρου φτιαγμένου για σώματα που δεν μπορούν να καθίσουν ακίνητα. Μουσική Γιώργου Στεφανακίδη. Για παιδιά από δέκα μηνών έως δυόμισι ετών.

Αν θέλετε το παιδί σας καθισμένο ήσυχα για δύο ώρες, αυτή δεν είναι η παράστασή σας. Αν όμως θέλετε η πρώτη του επαφή με το θέατρο να γίνει με τους δικούς του όρους — μπουσουλώντας, δείχνοντας, γελώντας — εδώ αρχίζει.

Olvio, Ιερά Οδός 67, Βοτανικός. Κυριακές 10:30. Εισιτήρια 9 EUR.

Σαράντα λεπτά είναι ακριβώς αρκετά όταν το κοινό σου μετράει την προσοχή σε δευτερόλεπτα.

---

**Τι άλλαξε:**

1. Ο anchor πήγε πρώτος — «είναι παράσταση κουκλοθέατρου...»
2. Η αισθητηριακή εικόνα μετακινήθηκε δεύτερη — δεν χάθηκε, αναδιατάχθηκε
3. Προστέθηκε «Αθήνα» στον anchor
4. Η ηλικιακή ομάδα μπήκε ρητά (binary decision field για γονείς)
5. Η ίδια voice, ο ίδιος closer — μόνο η σειρά διορθώθηκε

## Exemplar D: Compact Classical — Ρεσιτάλ Πιάνου Ευστρατιάδη

**Τύπος:** Ρεσιτάλ (classical) | **Εύρος:** 70-100 λέξεις | **Δομή:** Three-part block | **Register:** Πληθυντικό

Αυτό το exemplar δείχνει πώς προστίθεται filter sentence σε compact description, και χρησιμοποιεί αποδεκτή anchor παραλλαγή («δίνει ρεσιτάλ» αντί «είναι»).

---

Η Μαρία Ευστρατιάδη δίνει ρεσιτάλ πιάνου στον Φιλολογικό Σύλλογο Παρνασσός στο κέντρο της Αθήνας, στις 24 Μαρτίου 2026 στις 20:30. Η νεοκλασική αίθουσα του 1891 στην Ομήρου 8 κρατά ακουστική που δεν χρειάζεται ενίσχυση.

Η Ευστρατιάδη διευθύνει το τμήμα πιάνου του Ωδείου Αθηνών. Πρόγραμμα: δύο σονάτες Mozart (K. 283, K. 333) και Μπαλάντα αρ. 1 Chopin.

Αν θέλετε πιάνο με ενίσχυση σε μεγάλη αίθουσα, ο Παρνασσός δεν δουλεύει έτσι. Αν θέλετε Mozart σε αίθουσα που φιλοξενεί μη ενισχυμένη μουσική από το 1891, η καρέκλα περιμένει.

Εισιτήρια 7-15 EUR μέσω TicketServices. Μετρό Πανεπιστήμιο, πέντε λεπτά.

Το ίδρυμα επιστρέφει για τρίτη συνεχόμενη χρονιά. Κάθε εγγραφή χρηματοδοτεί αγορά δέντρων για αναδάσωση στο σημείο του αγώνα — τρέχεις μέσα στο τοπίο που βοηθάς να ξαναχτιστεί. Τρεις αποστάσεις: 10 χλμ, 5 χλμ, 1 χλμ για παιδιά. Ατομική χρονομέτρηση και αναμνηστικό μπλουζάκι για όλους.

Εγγραφή 10 EUR ενήλικες, ελεύθερη είσοδος για παιδιά κάτω των 12. Εκκίνηση 10:00. Κράτηση μέσω more.com.

# ΜΕΡΟΣ 10: QUALITY GATE CHECKLIST (ΕΛΛΗΝΙΚΑ)

Κάθε ελληνική περιγραφή πρέπει να περάσει αυτούς τους ελέγχους πριν τη δημοσίευση:

```
□ 1.  Πρώτη πρόταση = δηλωτικό anchor «είναι» (ή αποδεκτή παραλλαγή, βλ. Μέρος 2) με 6 entities
      (όνομα, τύπος, χώρος, γειτονιά, Αθήνα, ημερομηνία)
□ 2.  Αισθητηριακή μεταφορά ΜΕΤΑ τον anchor
      (ενεστώτας, β' πρόσωπο, 2+ αισθήσεις)
□ 3.  Ενεστώτας χρόνος σε ολόκληρο το κείμενο
□ 4.  Κοινό περιγράφεται με χαρακτήρα, όχι δημογραφικά
□ 5.  Filter section παρών και ειλικρινής
      («Αν θέλετε... / Αν όμως θέλετε...»)
□ 6.  Μηδέν απαγορευμένες λέξεις (βλ. Μέρος 6)
□ 7.  Good to Know = insider γνώση (θα το έλεγε ένας ντόπιος;)
□ 8.  Differentiation συγκεκριμένη (όχι «καλύτερος» ή «μοναδικός»)
□ 9.  Word count εντός ελληνικού matrix (Μέρος 4)
□ 10. Κανένα tag ή timestamp μέσα στο κείμενο
□ 11. Γειτονιά αναφέρεται
□ 12. Πλησιέστερος σταθμός μετρό (ή εναλλακτική πρόσβαση αν δεν υπάρχει)
□ 13. Τουλάχιστον 1 insider detail εκτός listing
□ 14. Citability test (≥2 standalone factual sentences μόνο γι' ΑΥΤΟ το event)
□ 15. Opening paragraph ≤50 λέξεις
□ 16. Κανένας markdown πίνακας στην περιγραφή
□ 17. Register (ενικό/πληθυντικό) ταιριάζει με τον χώρο
□ 18. Ονόματα χώρων στο σωστό script (βλ. Μέρος 3)
□ 19. Διευθύνσεις στα ελληνικά
□ 20. Closer δεν ανταλλάσσεται με άλλη περιγραφή του batch
□ 21. Ορθογραφικός και τονικός έλεγχος
```

### Ελληνικός Citability Test

Ένα AI engine πρέπει να μπορεί να εξάγει τουλάχιστον **2 αυτοτελείς προτάσεις** που:
1. Περιέχουν συγκεκριμένη, factual πληροφορία
2. Βγάζουν νόημα χωρίς τον γύρω τους context
3. Δεν δουλεύουν αν αντικαταστήσεις τον καλλιτέχνη/χώρο

Η μόνη διαφορά από τον αγγλικό test: τα ελληνικά anchors στοχεύουν ελληνόφωνα AI queries — «τι παίζει στην Αθήνα αυτό το σαββατοκύριακο,» «παιδικές παραστάσεις Αθήνα Μάρτιος 2026,» «techno βραδιές Γκάζι.»

## Η secondary δεν είναι μετάφραση

Η secondary γλώσσα γράφεται ΑΠΟ ΤΗΝ ΑΡΧΗ, ακολουθώντας τους κανόνες της δικής της γλώσσας. Δεν μεταφράζεται word-for-word. Ο anchor, η δομή, τα quality gates είναι ίδια — η εκτέλεση είναι native σε κάθε γλώσσα.

Αν υπάρχει πίεση χρόνου: γράψε μόνο τη primary γλώσσα. Η secondary μπορεί να γίνει αργότερα. Ένα hand-crafted description σε μία γλώσσα είναι καλύτερο από δύο βιαστικά descriptions.

# ΜΕΡΟΣ 12: ΚΕΝΑ ΠΟΥ ΠΑΡΑΜΕΝΟΥΝ

Αυτά τα σημεία χρειάζονται data πριν τεκμηριωθούν:

1. **Ελληνόφωνα AI citation patterns:** Ποια AI engines (Google AI Overview, Perplexity, ChatGPT) σερβίρουν ελληνικό content σε ελληνικά queries; Πώς κάνουν extraction; Είναι το «είναι» pattern εξίσου αποτελεσματικό στα ελληνικά; Χρειαζόμαστε A/B data.

2. **86% συντελεστής — σταθερός ή μεταβλητός;** Η αναλογία 86% προέρχεται από ένα batch 15 descriptions, κυρίως kids events. Μπορεί να διαφέρει σε exhibitions ή DJ sets. Χρειάζονται περισσότερα data points πριν γίνει σκληρός κανόνας.

3. **Ελληνικό closer repertoire:** Το αγγλικό template έχει 6 τύπους closers (scarcity, cost reframing, character wit, return narrative, seasonal window, mission statement). Χρειαζόμαστε ελληνικά παραδείγματα για κάθε τύπο — μερικά υπάρχουν στα exemplars, αλλά δεν καλύπτουν όλους.

4. **Search query patterns στα ελληνικά:** Ποιες ελληνικές αναζητήσεις φέρνουν traffic; «παιδικές παραστάσεις Αθήνα» vs «θέατρο για παιδιά» vs «τι να κάνω με παιδιά Αθήνα σαββατοκύριακο» — αυτό επηρεάζει ποια keywords πρέπει να μπαίνουν στον anchor.
